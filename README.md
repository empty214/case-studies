# case-studies

Short case studies, one folder each, published with GitHub Pages. Each study is a self-contained `index.html` with its own link, plus a PDF export for LinkedIn Featured.

- No external scripts, fonts or trackers.
- No school, client or employer names and no branding. Keep it that way: this repo is public.
- No personal data in any screenshot. Check every image before it goes in.
- Source text and approvals live in the private applications repo under `kb/linkedin/casestudies/`.
